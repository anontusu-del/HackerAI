# HackerAI Workspace

## 🚀 GMB Pro Dashboard

Google My Business / Google Business Profile (GMB) ও Listing কাজের জন্য প্রফেশনাল ট্র্যাকিং ড্যাশবোর্ড।

- 🌍 ১৫০+ দেশে বিজনেস সার্চ · ⭐ রেটিং ও রিভিউ কাউন্ট · ✅ GMB কমপ্লিটনেস স্কোর
- 🗺️ ইন্টারেক্টিভ ম্যাপ · 📥 CSV এক্সপোর্ট · 💾 সেভড লিস্ট
- 🎯 API Key ছাড়াই **ডেমো মোডে** চলবে — Codespaces খুললেই অটো-স্টার্ট ও পোর্ট ফরওয়ার্ড

**▶️ এখনই চালান:** এই রিপোর **Code → Codespaces → + Create codespace on main** চাপুন।
সার্ভার নিজে থেকে চালু হবে এবং `http://localhost:3000` ব্রাউজারে অটো খুলবে।

📖 সম্পূর্ণ বাংলা ডকুমেন্টেশন: **[gmb-pro-dashboard/README.md](gmb-pro-dashboard/README.md)**

```
gmb-pro-dashboard/   ← মূল প্রজেক্ট (সার্ভার + ড্যাশবোর্ড + ডক)
.devcontainer/       ← Codespaces অটো-স্টার্ট কনফিগ (পোর্ট 3000)
```
