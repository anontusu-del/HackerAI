# GMB Pro Dashboard 🚀

**Google My Business / Google Business Profile (GMB) & Listing কাজের জন্য প্রফেশনাল ট্র্যাকিং ড্যাশবোর্ড।**

যেকোনো দেশের যেকোনো ব্যবসা সার্চ করুন → গুগল ম্যাপে দেখুন → রেটিং ও রিভিউ সংখ্যা দেখুন → **GMB কমপ্লিট (সম্পূর্ণ) কিনা** অটো হিসাব করুন → রিপোর্ট CSV হিসেবে ডাউনলোড করুন → লিস্ট সেভ করে রাখুন।

## ১। এই টুলে যা যা আছে (Features)

| ফিচার | বর্ণনা |
|---|---|
| 🌍 যেকোনো দেশ | ১৫০+ দেশের লিস্ট; নির্বাচিত দেশেই সার্চ হবে |
| 🔍 বিজনেস সার্চ | keyword + দেশ + ব্যবসার ধরন (রেস্টুরেন্ট, ডেন্টিস্ট, হোটেল, জিম…) |
| 🗺️ ইন্টারেক্টিভ ম্যাপ | প্রতিটি ব্যবসা মার্কার সহ; ক্লিক করলে ডিটেইলস |
| ⭐ রেটিং ও রিভিউ | প্রতিটি লিস্টিং-এর রেটিং ও মোট রিভিউ সংখ্যা |
| ✅ GMB কমপ্লিটনেস স্কোর | ৬টি ফিল্ড (ফোন, ওয়েবসাইট, আওয়ার, ছবি, ডেসক্রিপশন, রিভিউ) চেক করে ০–১০০% স্কোর |
| ⚠️ মিসিং ফিল্ড | কোন ফিল্ড নাই — ক্লায়েন্টকে কোনটা ঠিক করতে হবে তা চিপ আকারে দেখায় |
| 📥 CSV এক্সপোর্ট | Excel-এ খোলা যায় এমন রিপোর্ট (Unicode/Bangla সহ) |
| 💾 সেভড লিস্ট | একাধিক প্রজেক্ট সেভ করে রাখুন, পরে আবার দেখুন |
| 📊 স্ট্যাটস কার্ড | মোট লিস্টিং, গড় রেটিং, মোট রিভিউ, কমপ্লিট/নিডস ওয়ার্ক সংখ্যা |
| 🔍 ফিল্টার ও সর্ট | স্ট্যাটাস (Open/Closed), কমপ্লিটনেস, সর্টিং |

**Demo Mode:** API Key ছাড়াই টুলটি চলবে (মক ডেটা সহ) — পুরো ইউআই দেখতে পারবেন। Key দিলেই লাইভ গুগল ডেটা।

## ২। যা যা লাগবে (Requirements)

1. **Node.js** — বিনামূল্যে ডাউনলোড: https://nodejs.org (LTS ভার্সন)
2. **Google Account** — https://console.cloud.google.com
3. **Google API Key** (নিচের ধাপে বানানো যাবে) — প্রথমবার দেওয়া $300 ফ্রি ক্রেডিট আছে

## ৩। Google API Key বানানোর ধাপ (একবারই করতে হবে)

1. **Google Cloud Console** খুলুন → https://console.cloud.google.com
2. উপরে **"Create Project"** → নাম দিন যেমন `gmb-tools` → Create
3. উপরের সার্চ বারে গিয়ে **"Enable APIs and Services"** → **এই ২টা API Enable করুন:**
   - `Places API` (নতুন version auto)
   - `Maps JavaScript API`
4. বাম মেনু থেকে **Billing** → **Link billing account** → কার্ড/বিলিং যোগ করুন (যেকোনো দেশের কার্ড)
5. বাম মেনু থেকে **APIs & Services → Credentials**
6. **+ Create Credentials → API key** → নতুন Key কপি করুন
7. (প্রফেশনাল সেফটির জন্য) Key-এর পাশে ✏️ **Edit API key** → **Application restrictions: HTTP referrers** → সেখানে যোগ করুন:
   - `http://localhost:*`
   - `http://localhost:3000/*`
   - আপনার ভবিষ্যৎ ডোমেইন (যেমন `https://yourdomain.com/*`)
   - **API restrictions → Restrict key** → শুধু `Places API` ও `Maps JavaScript API` টিক দিন → Save

> 💰 খরচ: Places API Text Search ~$32/১০০০ সার্চ, Place Details ~$17/১০০০। সাধারণ ব্যবহারে মাসে কয়েক ডলারই লাগে। ফ্রি ক্রেডিটেও অনেকদিন চলবে।

## ৪। কীভাবে চালাবেন (Run)

### ✨ GitHub Codespaces (সবচেয়ে সহজ — API Key লাগে না)

এই রিপোর **Code** বাটন → **Codespaces** ট্যাব → **+ Create codespace on main** চাপুন।

সবকিছু **অটো** হয়ে যাবে:
- সার্ভার নিজে থেকেই চালু হবে (`.devcontainer/post-start.sh`)
- **পোর্ট 3000 অটো-ফরওয়ার্ড** হয়ে ব্রাউজারে ট্যাব নিজে থেকেই খুলবে
- API Key না থাকলেও **ডেমো মোডে** পুরো ড্যাশবোর্ড কাজ করবে

> 💡 মোবাইলেও কাজ করে! GitHub অ্যাপ/ব্রাউজারে Codespace খুললেই ড্যাশবোর্ড দেখতে পাবেন।
> 💡 **লাইভ গুগল ডেটা** চাইলে পরে Codespace-এর Terminal-এ `touch .env` লিখে `.env` ফাইলে `GOOGLE_API_KEY=...` বসিয়ে সার্ভার রিস্টার্ট করুন।

### Windows
1. `gmb-pro-dashboard` ফোল্ডারে ঢুকুন
2. `.env.example` ফাইলটি কপি করে নাম দিন `.env`
3. `.env` ফাইলে `GOOGLE_API_KEY=আপনার_কি` বসান
4. **`start.bat`** ডাবল-ক্লিক করুন
5. ব্রাউজারে খুলুন: **http://localhost:3000**

### Mac / Linux
```bash
cd gmb-pro-dashboard
cp .env.example .env   # তারপর .env-এ key বসান
chmod +x start.sh
./start.sh
```

> কোনো এক্সট্রা ইনস্টল লাগে না — কোনো npm dependency নেই, শুধু Node.js।

## ৫। ব্যবহারের গাইড (কীভাবে কাজ করবে)

1. **সার্চ করুন** — যেমন `dentist` লিখুন, দেশ **Bangladesh** (বা যেকোনো দেশ) বাছুন → **Search**
2. ফলাফল পাবেন — বামে ম্যাপ, ডানে প্রতিটি ব্যবসার কার্ড
3. প্রতিটি কার্ডে দেখবেন:
   - ⭐ রেটিং ও রিভিউ সংখ্যা
   - ✅ **X% Complete** — GMB কতটা সম্পূর্ণ
   - 🔴 মিসিং চিপ — যেমন "Missing: Website", "Missing: Photos"
   - Open/Temp closed/Closed স্ট্যাটাস
4. **View Details** — সম্পূর্ণ ডিটেইলস: ফোন, ওয়েবসাইট, আওয়ার, চেকলিস্ট, সর্বশেষ রিভিউ
5. **Save List** — লিস্ট সেভ করুন (যেমন "Dhaka Dentists — August")
6. **Saved Lists** — আগের লিস্ট আবার দেখুন
7. **Export CSV** — Excel-এ ক্লায়েন্ট রিপোর্ট তৈরি করুন

**প্রো টিপ:** কোনো ক্লায়েন্টের GMB করতে — আগে তার ব্যবসার নাম/এলাকা সার্চ করুন। স্কোর কম মানে বুঝবেন কোন ফিল্ড পূরণ করা বাকি (ফোন/ওয়েবসাইট/ছবি/আওয়ার)। ক্লায়েন্টকে সেটাই ঠিক করতে বলুন, রেটিং ও রিভিউ বাড়ানোর প্ল্যান দিন। 📈

## ৬। GMB কমপ্লিট স্কোর — কিভাবে হিসাব হয়

পাবলিক Places ডেটা থেকে ৬টি ফিল্ড চেক হয়:

| ফিল্ড | গুরুত্ব |
|---|---|
| ফোন নম্বর | ১৬.৭% |
| ওয়েবসাইট | ১৬.৭% |
| Opening hours | ১৬.৭% |
| ছবি | ১৬.৭% |
| ডেসক্রিপশন | ১৬.৭% |
| রিভিউ (কমপক্ষে ১টি) | ১৬.৭% |

- **৯০%+** → Complete ✅ (সবুজ)
- **৫৫–৮৯%** → Partial ⚠️ (হলুদ)
- **<৫৫%** → Incomplete 🔴 (লাল)

> ⚠️ **গুরুত্বপূর্ণ সতর্কতা:** Google-এর পাবলিক Places API তে **"লিস্টিংটি মালিক ক্লেইম/ভেরিফাই করেছেন কিনা"** সেটা আসে না। তাই এখানে "GMB কমপ্লিটনেস" = প্রোফাইলের তথ্য কতটা ভরা — সেটাই। **আসল ভেরিফিকেশন স্ট্যাটাস** (claimed by owner) জানতে হলে লাগবে **Google Business Profile API** (OAuth + Google-এর অ্যাপ রিভিউ) — এটি ভবিষ্যতে যোগ করা যাবে, নিচের রোডম্যাপ দেখুন।

## ৭। ফোল্ডার স্ট্রাকচার

```
gmb-pro-dashboard/
├── server.js          ← Node.js সার্ভার (কোনো dependency নেই)
├── .env.example       ← API key বসানোর টেমপ্লেট
├── start.bat          ← Windows চালু করার ফাইল
├── start.sh           ← Mac/Linux চালু করার ফাইল
├── public/
│   ├── index.html     ← ড্যাশবোর্ড
│   ├── style.css      ← ডিজাইন
│   └── app.js         ← ফ্রন্টএন্ড লজিক
├── data/
│   └── saved-projects.json  ← সেভড লিস্ট (অটো তৈরি হয়)
└── README.md          ← এই ফাইল (বাংলা)
```

**কীভাবে কাজ করে:** ব্রাউজার → আপনার লোকাল সার্ভার (`server.js`) → Google Places API। মানে **API Key কখনো ব্রাউজার/ক্লায়েন্টের কাছে যায় না** (শুধু ম্যাপ দেখানোর জন্য ছোট্ট অংশে, referrer restriction দিয়ে সুরক্ষিত)। API ফিরিয়ে আনে: নাম, ঠিকানা, ফোন, ওয়েবসাইট, রেটিং, রিভিউ সংখ্যা, আওয়ার, ছবি, স্ট্যাটাস।

## ৮। ভবিষ্যৎ আপগ্রেড আইডিয়া (লং-টার্ম প্রফেশনাল প্ল্যান)

1. **ক্লায়েন্ট ম্যানেজমেন্ট** — প্রতিটি ক্লায়েন্টের নিজস্ব প্রজেক্ট, মাসিক রিপোর্ট
2. **Google Business Profile API** — আসল ভেরিফিকেশন স্ট্যাটাস (claimed/verified), রিভিউ রিপ্লাই, নতুন লিস্টিং তৈরি
3. **লগইন/পাসওয়ার্ড** — টিমের সাথে শেয়ার করার জন্য
4. **অটো-রিপোর্ট** — প্রতি সপ্তাহে/মাসে অটো CSV/PDF ইমেইল
5. **রিভিউ ট্রেন্ড চার্ট** — সময়ের সাথে রেটিং পরিবর্তনের গ্রাফ (Places API-তে শুধু বর্তমান সংখ্যা আসে)
6. **বাল্ক লিস্টিং চেক** — একসাথে ১০০+ ব্যবসা আপলোড করে স্কোর বের করা
7. **ডিপ্লয়** — VPS/Google Cloud Run-এ বসিয়ে সবাই ব্যবহার করতে পারবে

> আপনার কাজের নিয়ম (কোন দেশ, কোন ক্যাটাগরি, কতগুলো লিস্টিং) বলুন — আমি সে অনুযায়ী ডিফল্ট সেটআপ করে দিতে পারি, এমনকি উপরের যেকোনো ফিচার যোগ করে দিতে পারি। 👊
